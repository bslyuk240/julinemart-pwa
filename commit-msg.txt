Switch Android OAuth to HTTPS redirect URI (App Links)

Changed from custom URI schemes to HTTPS redirect URIs (App Links), which is the modern recommended approach for Android OAuth in 2026. Custom URI schemes are being deprecated by Google.

- Updated redirect URI to https://dev-lab--julinemart-pwa.netlify.app/auth/google/callback
- Created OAuth callback page
- Updated deep link handler for HTTPS URLs

This fixes the "Custom URI scheme is not enabled" error.
